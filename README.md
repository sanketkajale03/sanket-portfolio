# Sanket's Personal Portfolio

A responsive personal portfolio website built using HTML, CSS, and Vanilla JavaScript.

## Technologies

- HTML5
- CSS3
- JavaScript (ES Modules)

## Features

- Multiple portfolio pages
- Dark and light themes
- Responsive design
- Reusable components
- Modular JavaScript architecture

## Development

Open this project in Visual Studio Code and run it using the Live Server extension.
